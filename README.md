# My Personal Portfolio

Welcome to my Personal Portfolio Website! 

This website showcases my personal profile, educational background, technical skills, projects, certifications, and contact information. It serves as a platform to present my knowledge, experiences, and development as a Computer Science student.

## About the Project

The Personal Portfolio is a responsive website designed to introduce myself and showcase my skills and projects. It provides visitors with an overview of my academic background, technical abilities, accomplishments, and sample works.

## Technologies Used

- **HTML5** – Used to structure the website.
- **CSS3** – Used for styling, layouts, animations, and responsive design.
- **JavaScript** – Used to add interactivity and functionality.

## Features

- **Home** – Displays my profile and introduction.
- **About Me** – Provides information about myself.
- **Education** – Showcases my academic background.
- **Skills** – Displays my technical skills and proficiency levels.
- **Projects** – Presents my completed and ongoing projects.
- **Certifications** – Displays my certificates and achievements.
- **Contact** – Provides ways to connect with me.
- **Dark/Light Mode** – Allows users to switch between themes.
- **Interactive Navigation** – Allows visitors to navigate between portfolio sections.
- **Responsive Design** – Designed to work on different screen sizes.

## Projects Featured

- **Pinyin Product Scanner** – A product-scanning application concept.
- **Crab Classification System** – A project focused on crab species identification and classification.

## Installation and Usage

To run this project locally:

1. Clone this repository:

   ```bash
   git clone https://github.com/dabalosjia-netizen/portfolio.git
   ```

2. Open the project folder.
3. Open `index.html` in your preferred web browser.
