WEB DEVELOPMENT PROJECT

Pinyin Product Scanner

Pinyin is a web-based product scanning and price lookup application designed to make product information more accessible and convenient for customers.

Project Objectives

  • Provide an easy way to search for product information.
  • Allow customers to check product prices conveniently.
  • Reduce the time spent manually searching for products.
  • Provide a user-friendly product lookup experience.

Key Features

  • Barcode scanning using a camera.
  • Manual barcode and product search.
  • Product information and price display.
  • Shopping cart management.
  • Admin dashboard for product management.

Technologies Used

Python, Django, HTML, CSS, JavaScript, SQLite, HTML5-QRCode

MACHINE LEARNING PROJECT

Crab Classification System

CrabLens is an image-based crab classification and detection system that uses CNN and YOLOv8 to identify different crab species through uploaded images and real-time camera detection. It aims to promote awareness and provide information about crab species and their classification as edible or non-edible based on available references.

Project Objectives

  • Identify and classify different crab species.
  • Help distinguish edible and non-edible crab species based on references.
  • Provide convenient crab identification through a mobile application.
  • Promote awareness about crab species and safety.

Key Features

  • Manual image upload and detection.
  • Real-time camera detection.
  • Crab species classification.
  • YOLO bounding box visualization.
  • Display of crab species information.

Technologies Used

Python, CNN, YOLOv8, OpenCV, Roboflow, Google Colab
